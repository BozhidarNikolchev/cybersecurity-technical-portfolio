# Device Investigation Side Quest

## Platform

TryHackMe

## Path

Pre Security

## Module

Introduction to Cyber Security

## Overview

This side quest simulated the examination of a confiscated device. The objective was to inspect hardware components, understand their purpose, and gather information that could assist an investigation.

The exercise demonstrated how physical devices and their components can provide valuable information during security investigations.

---

## Learning Objectives

- Identify common computer hardware components.
- Understand the role of each component.
- Develop observation and investigation skills.
- Recognize the importance of physical evidence in cybersecurity.

---

## Components Examined

### Motherboard

The motherboard connects and allows communication between all major hardware components.

### CPU

The Central Processing Unit (CPU) performs calculations and executes instructions.

### RAM

Random Access Memory (RAM) temporarily stores data currently being used by the system.

### Storage Device

A hard disk drive (HDD) or solid-state drive (SSD) stores operating systems, applications, and user data.

### Power Supply

The power supply provides electricity to all internal components.

### Networking Components

Network hardware enables communication with other systems and networks.

---

## Investigation Concepts

- Hardware can contain valuable evidence.
- Physical access to a computer can reveal useful information.
- Security investigations may involve both digital and physical examination.
- Understanding system architecture helps investigators interpret findings.

---

## Lessons Learned

- Cybersecurity investigations are not limited to software.
- Hardware knowledge is important for analysts and investigators.
- Individual computer components serve specific roles within a system.
- Physical evidence can contribute to incident investigations.

---

## Key Takeaways

- A computer consists of multiple interconnected components.
- Understanding hardware improves overall cybersecurity knowledge.
- Investigations can involve both physical and digital evidence.
- Hardware awareness is a valuable skill for security professionals.
