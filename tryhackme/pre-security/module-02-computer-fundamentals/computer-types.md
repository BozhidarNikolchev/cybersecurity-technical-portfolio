## Overview

This room introduced the different types of computers used in modern technology environments. While many users interact directly with personal devices such as laptops and smartphones, numerous other computer systems operate behind the scenes to deliver services, manage networks, automate processes, and power everyday technology.

The room explored several categories of computers and explained why each type is designed for specific purposes.

---

## Learning Objectives

- Identify different types of computers.
- Understand the purpose of each computer category.
- Distinguish between personal computers and enterprise systems.
- Understand how embedded and IoT devices operate.
- Recognize how different computer systems interact within modern environments.

---

## Computer Types

### Desktop Computers

Desktop computers are designed for stationary use and are commonly found in homes, schools, and offices.

Characteristics:

- Larger form factor
- Easily upgradeable
- High performance
- External monitor, keyboard, and mouse

Common Uses:

- Office work
- Gaming
- Programming
- Multimedia production

---

### Laptop Computers

Laptops provide portable computing while offering functionality similar to desktop systems.

Characteristics:

- Portable
- Battery powered
- Integrated display, keyboard, and touchpad
- Wireless connectivity

Common Uses:

- Remote work
- Education
- Travel
- Everyday computing

---

### Smartphones

Smartphones are handheld computers designed for communication and mobile applications.

Characteristics:

- Touchscreen interface
- Mobile operating systems
- Internet connectivity
- Built-in sensors and cameras

Common Uses:

- Communication
- Mobile applications
- Web browsing
- Navigation

---

### Tablets

Tablets combine portability with larger displays than smartphones.

Characteristics:

- Touchscreen interface
- Lightweight design
- Mobile operating systems
- Long battery life

Common Uses:

- Media consumption
- Education
- Business presentations
- Mobile productivity

---

### Servers

Servers are computers designed to provide services, resources, or applications to other systems across a network.

Characteristics:

- High reliability
- Continuous operation
- Large storage capacity
- Multiple users supported simultaneously

Common Services:

- Web hosting
- File storage
- Email services
- Database management

---

### Internet of Things (IoT) Devices

IoT devices are computer systems connected to networks that perform specialized functions.

Examples:

- Smart TVs
- Smart thermostats
- Security cameras
- Smart speakers

Characteristics:

- Specialized tasks
- Network connectivity
- Minimal user interaction
- Automated operation

---

### Embedded Systems

Embedded systems are computers integrated into larger devices to perform dedicated functions.

Examples:

- Microwave ovens
- Automobiles
- Washing machines
- Medical devices

Characteristics:

- Task-specific
- Optimized for reliability
- Limited resources
- Operate without direct user control

---

## Why Different Computer Types Exist

Different computer systems are designed to meet different requirements.

Examples:

| Computer Type | Primary Purpose |
|--------------|----------------|
| Desktop | Performance and flexibility |
| Laptop | Portability |
| Smartphone | Mobile communication |
| Server | Providing services |
| IoT Device | Automation and connectivity |
| Embedded System | Dedicated control functions |

Each computer type balances factors such as:

- Performance
- Cost
- Power consumption
- Portability
- Reliability
- Functionality

---

## Cybersecurity Relevance

Understanding computer types is important because each category introduces different security considerations.

Examples:

### Personal Computers

- Malware infections
- Phishing attacks
- Data theft

### Servers

- Unauthorized access
- Service disruption
- Vulnerability exploitation

### IoT Devices

- Weak default credentials
- Outdated firmware
- Network exposure

### Embedded Systems

- Limited security controls
- Difficult patch management
- Long hardware lifecycles

Different systems require different security strategies.

## Lessons Learned

- Computers exist in many forms beyond desktops and laptops.
- Servers support services used by multiple users and applications.
- IoT devices are common in both homes and businesses.
- Embedded systems power many everyday devices.
- Different computer types are optimized for different purposes.
- Security requirements vary depending on the device type.
