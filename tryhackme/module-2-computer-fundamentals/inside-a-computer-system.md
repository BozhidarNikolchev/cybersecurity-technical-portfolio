## Overview

This room introduced the internal components of a computer system through a practical investigation scenario involving a confiscated machine. The objective was to identify hardware components, understand their purpose, and learn how they work together to create a functional computer.

The room highlighted how cybersecurity professionals, investigators, and forensic analysts may need to understand both hardware and software when examining a system.

- Identify the major internal components of a computer.
- Understand the function of each hardware component.
- Learn how computer components interact with one another.

## Investigation Scenario

A confiscated computer system was examined by performing a cold boot and inspecting its internal hardware components.

The exercise simulated a basic digital investigation where understanding the physical system is necessary before analyzing any software or data stored on the machine.

## Computer Components Examined

### Motherboard

The motherboard is the central circuit board that connects all hardware components.

Responsibilities:

- Enables communication between components
- Provides power connections
- Hosts expansion slots and interfaces
- Connects storage devices, memory, and processors

---

### Central Processing Unit (CPU)

The CPU is responsible for executing instructions and processing calculations.

Responsibilities:

- Executes operating system instructions
- Runs applications
- Performs calculations
- Processes data

Often referred to as the "brain" of the computer.

---

### Random Access Memory (RAM)

RAM temporarily stores data currently being used by the system.

Characteristics:

- Fast access speeds
- Temporary storage
- Contents are cleared when power is removed

Uses:

- Running applications
- Active operating system processes
- Temporary data storage

---

### Storage Device

Storage devices permanently store information.

Examples:

- SSD (Solid State Drive)
- HDD (Hard Disk Drive)

Stores:

- Operating systems
- Applications
- User files
- Logs
- Configuration data

---

### Power Supply Unit (PSU)

The power supply converts electrical power into usable power for computer components.

Responsibilities:

- Supplies power to the motherboard
- Powers storage devices
- Powers cooling systems
- Supports overall system operation

---

### Cooling System

Cooling components help maintain safe operating temperatures.

Examples:

- Fans
- Heat sinks

Purpose:

- Prevent overheating
- Improve stability
- Extend component lifespan

---

### Network Interface

Network hardware allows systems to communicate with other devices and networks.

Examples:

- Ethernet adapters
- Wireless adapters

Uses:

- Internet connectivity
- Internal network communication
- Data transfer

---

## How Components Work Together

A computer functions because each component performs a specific role.

Example workflow:

1. Data is stored on a storage device.
2. The operating system loads data into RAM.
3. The CPU processes instructions.
4. Results are displayed to the user.
5. Data may be written back to storage.

The motherboard coordinates communication between these components.

---

## Cybersecurity Relevance

Understanding hardware is important because:

- Investigations often involve physical devices.
- Evidence may be stored on storage media.
- Memory can contain valuable information.
- Hardware identification helps analysts understand system configurations.
- Different hardware components present different security considerations.

Examples include:

- Disk encryption
- Secure boot
- Hardware-based security modules
- Physical access controls

## Lessons Learned

- Computers are composed of multiple specialized components.
- Each component serves a unique purpose.
- Storage and memory perform different functions.
- Hardware knowledge supports cybersecurity investigations.
- Physical systems provide important evidence during investigations.
