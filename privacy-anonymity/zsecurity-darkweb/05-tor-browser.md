# Tor Browser

## What is Tor Browser?

The Tor Browser is a modified version of Firefox designed to route all traffic through the Tor network.

---

## Core Features

- Automatic Tor routing  
- Built-in privacy protections  
- Anti-tracking mechanisms  

---

## Purpose

✅ Anonymous web browsing  
✅ IP address masking  
✅ Protection against tracking  

---

## Key Insight

The browser is the user interface, while Tor is the underlying network.
