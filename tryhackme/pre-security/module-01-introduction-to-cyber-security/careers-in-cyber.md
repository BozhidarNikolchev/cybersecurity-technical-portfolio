## Key Concepts

### The Cybersecurity Industry

Cybersecurity is a broad field that contains many different specializations. Professionals work to protect systems, networks, applications, and data from cyber threats.

Career paths generally fall into several categories, including:

- Offensive Security
- Defensive Security
- Governance, Risk & Compliance (GRC)
- Security Engineering
- Digital Forensics
- Threat Intelligence
- Security Operations

---

### Penetration Tester

Penetration Testers simulate real-world attacks against systems and applications to identify vulnerabilities before malicious actors can exploit them.

Responsibilities include:

- Vulnerability discovery
- Security assessments
- Exploitation testing
- Security reporting

---

### Security Analyst

Security Analysts monitor and protect an organization's systems and networks from threats.

Responsibilities include:

- Monitoring security alerts
- Investigating suspicious activity
- Analyzing risks
- Producing security reports
- Improving defensive controls

---

### Security Engineer

Security Engineers design, implement, and maintain security solutions that protect organizational infrastructure.

Responsibilities include:

- Deploying security controls
- Hardening systems
- Managing security technologies
- Improving infrastructure security

---

### Digital Forensics Analyst

Digital Forensics Analysts investigate cyber incidents and collect evidence to determine what occurred during an attack.

Responsibilities include:

- Evidence collection
- Log analysis
- Incident investigation
- Reporting findings

---

### Incident Responder

Incident Responders handle active security incidents and coordinate remediation activities.

Responsibilities include:

- Threat containment
- Investigation
- Eradication of threats
- Recovery support
