# Side Quest - Phishing Awareness

## Platform

TryHackMe

## Path

Pre Security

## Module

Introduction to Cyber Security

## Overview

This side quest demonstrated how attackers collect publicly available information about targets and use it to create convincing phishing messages.

The exercise focused on identifying warning signs commonly found in phishing attacks and understanding how attackers use urgency, familiarity, and personal information to manipulate victims.

---

## Key Findings

### Phones Leak Information

Devices can reveal information such as:

- Device type
- Browser
- Language
- Time zone
- Location

Attackers can use this information to make phishing attempts appear more legitimate.

### Familiarity Does Not Equal Trust

Messages containing accurate personal information can still be fraudulent.

Always verify:

- Domain names
- Sender authenticity
- Website legitimacy

instead of trusting information contained within the message.

### Urgency Is A Common Social Engineering Technique

Attackers often create pressure using messages such as:

> "Act within 30 minutes"

The goal is to reduce critical thinking and encourage impulsive actions.

## Lessons Learned

- Personal information can be gathered from multiple sources.
- Phishing attacks often rely on trust and urgency.
- Verifying domains is more important than trusting message content.
- Defensive security begins with awareness and verification.

---

## Key Takeaways

- Check the domain, not the message.
- Be cautious of urgency-based requests.
- Personal information can be weaponized by attackers.
- Awareness is one of the strongest defenses against phishing.
