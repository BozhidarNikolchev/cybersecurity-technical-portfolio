# Limitations of TAILS

## Network Restrictions

- Many websites block Tor traffic
- Captchas are common
- Slower connection speeds

---

## Usability Limitations

- Cannot install traditional software
- Limited file access
- Restricted browser functionality

---

## Not Perfect Anonymity

TAILS does NOT protect against:

- user behavior tracking
- account login identity leaks
- human error

---

## Important Insight

Anonymity is not only technical — it also depends on user behavior.

---

## My Understanding

Even with strong tools like TAILS, mistakes at the user level can break anonymity.
