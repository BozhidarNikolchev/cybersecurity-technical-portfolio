# TAILS Summary

## Key Takeaways

- TAILS is a live OS focused on anonymity
- It routes all traffic through Tor
- It leaves no traces after shutdown
- It isolates applications and restricts access
- It is more secure than using Tor on a normal OS

---

## Core Concept

Security is strongest when both system and network are controlled.

---

## Personal Insight

Real anonymity requires:

- secure tools (TAILS)
- proper usage
- understanding of risks
