# TryHackMe Learning Journey

## Overview

This section of the repository contains my hands-on learning journey through TryHackMe.

The goal is not simply to complete rooms, but to document concepts, tools, techniques, and lessons learned throughout my cybersecurity training. Each room is summarized in a dedicated Markdown file that captures the most important takeaways and practical knowledge gained during the exercise.

---

## Learning Approach

I follow a structured approach for every room:

1. Complete the room.
2. Study the concepts introduced.
3. Research unfamiliar technologies and terminology.
4. Document key findings and lessons learned.
5. Organize notes into GitHub-friendly Markdown files.
6. Build a long-term cybersecurity knowledge portfolio.

This repository serves as both a learning journal and a demonstration of continuous professional development.
