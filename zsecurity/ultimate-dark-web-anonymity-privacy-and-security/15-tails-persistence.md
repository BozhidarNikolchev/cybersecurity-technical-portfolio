# TAILS Persistence

## What is Persistence?

Persistence allows saving data between sessions using encrypted storage.

---

## Default Behavior

- No persistence enabled
- All data is lost after shutdown

---

## With Persistence Enabled

- Encrypted partition created
- Selected files and settings saved
- Requires password for access

---

## Security Trade-off

Without persistence:
- Maximum privacy

With persistence:
- More usability
- Slightly increased risk

---

## My Understanding

Persistence introduces a balance between usability and security.
