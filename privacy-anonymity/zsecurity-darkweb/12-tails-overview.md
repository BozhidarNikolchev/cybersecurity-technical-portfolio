# TAILS - The Amnesic Incognito Live System

## What is TAILS?

TAILS (The Amnesic Incognito Live System) is a privacy-focused operating system designed to preserve anonymity.

It runs from a USB stick and operates independently of the host operating system.

---

## Core Characteristics

- Live OS (runs from USB)
- Does not require installation
- Routes all traffic through Tor
- Leaves no traces after shutdown (amnesic)

---

## Key Purpose

TAILS is designed to:

- protect user identity
- prevent data persistence
- reduce system-level tracking risks

---

## Key Insight

TAILS provides system-level anonymity, not just browser-level privacy.
